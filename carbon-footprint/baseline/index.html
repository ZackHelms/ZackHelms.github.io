Maxing a 7-day quota, every week

Method: Anthropic publishes no token budgets, so I start from measured API-dollar value of a full weekly limit, then convert dollars to energy using Hausfather's logged Claude Code usage (3.2B tokens, 96% cache reads, about $0.80 per million tokens at Opus-class list prices, 170 kWh with a 70-330 range). That gives roughly 27 / 66 / 129 Wh per API dollar for min / central / max. inferred
