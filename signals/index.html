SIGNALS

Every kind of signal a web app can monitor — feature-detected and probed live in the browser you are holding right now. Green badges are measured, not claimed. Notes on iPhone support and on what needs a native app are editorial.

detecting…
LIVE readable right now PERMISSION present, needs your consent or a tap ABSENT no API in this browser NATIVE no web API anywhere — needs an app

Method. Status badges come from real feature detection and, where a probe exists, from actually starting the signal and reading it. Absent means absent here — the same page on a different device will score differently, which is the point. Nothing is uploaded anywhere; every probe runs locally and the page has no analytics, no backend and no third-party code (Google Fonts is the only external request).

Source: one self-contained HTML file in ZackHelms.github.io / signals/.
